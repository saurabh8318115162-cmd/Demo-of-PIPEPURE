# PIPEPURE --- Master Control Centre

A browser-based water-system monitoring and simulation dashboard.
PIPEPURE demonstrates how a home or large-building water system could be
monitored, how rule-based alerts can be raised, and how flushing and
non-potable water reuse workflows could be represented in a control
interface.

> **Important:** This project is currently a front-end simulation. It
> does not connect to real sensors, pumps, valves, controllers, or water
> infrastructure. All readings and device states shown in the interface
> are simulated.

## Features

-   **Overview dashboard** --- displays tank level, water-quality
    estimates, pipeline flow, pressure, maintenance status, reuse
    status, alerts, trend charts, and an event log.
-   **3D house model** --- interactive Three.js model with selectable
    components, camera controls, and a cutaway view.
-   **Smart flushing simulation** --- demonstrates a staged flushing
    cycle, pre-flight safety checks, waste collection, and cycle
    history.
-   **Water reuse workflow** --- illustrates a separate non-potable
    treatment path with a verification gate before reuse.
-   **Large-scale mode** --- simulates distribution zones, metered flow,
    pressure, storage, and a possible leak scenario.
-   **Operating modes** --- Auto, Manual, and Safe modes, plus an
    emergency-stop control.
-   **Scenario simulator** --- adjust readings and load preset scenarios
    such as cloudy water, low tank level, a pipeline leak, maintenance
    due, a full waste tank, and sensor failure.
-   **Responsive layout** --- adapts the dashboard for narrower screens.

## Technology

-   HTML5
-   CSS3
-   Vanilla JavaScript
-   [Three.js](https://threejs.org/) r128 for the 3D model
-   Google Fonts: Inter and Space Grotesk

The current page loads Three.js, Google Fonts, and the library
dependencies from public CDNs, so an internet connection is required for
those resources.

## Run locally

No build step or package installation is required for the current
front-end demo.

1.  Download or clone this project.
2.  Keep the HTML file in its project folder.
3.  Open the HTML file in a modern browser.

For a local development server, open a terminal in the project folder
and run:

``` bash
python -m http.server 8000
```

Then open:

``` text
http://localhost:8000
```

If the HTML file has a different name, open that filename through the
local server.

## Using the dashboard

1.  Open **Overview** to see the simulated system status.
2.  Use the **Simulator** panel to change values such as tank level,
    turbidity, pH, TDS, flow, pressure, and waste-tank level.
3.  Select a preset under **Scenarios** to load a demonstration
    condition.
4.  Open **3D house model** to inspect the simulated components. Drag to
    rotate, use Shift-drag or right-click-drag to pan, and use the mouse
    wheel to zoom.
5.  Open **Flushing and sediment** to review checks and demonstrate a
    flushing cycle.
6.  Open **Water reuse** to demonstrate the separate treatment and
    verification workflow.
7.  Select **Large-scale** to view the simulated building/society
    distribution zones.
8.  Use **About PIPEPURE** for the in-app description and limitations.

The dashboard updates its simulated readings approximately once per
second. Some actions are intentionally blocked when the demo safety
checks fail.

## Demo logic and safety notes

-   Alerts are generated by JavaScript threshold and persistence rules.
    **There is no trained machine-learning model.**
-   Readings are generated in the browser and are not measurements from
    real instruments.
-   The displayed pH, turbidity, TDS/estimated conductivity,
    temperature, and optional chlorine values cannot establish that
    water is safe to drink.
-   The interface itself notes that laboratory verification is separate
    and is not on file in the demo.
-   A suspected leak is an indication from simulated flow imbalance and
    pressure, not a confirmed diagnosis or precise leak location.
-   Flushing is represented as a simulated sequence. The demo notes that
    flushing clears loose sediment only; it does not remove attached
    corrosion, hard scale, biofilm, dissolved chemicals, or microbes.
-   The reuse workflow is presented as a separate **non-potable**
    system. Untreated wastewater and flushing discharge are not
    automatically routed into drinking-water pipes.
-   Do not connect this demo directly to pumps, valves, or a live water
    supply. Real installations require qualified engineering, validated
    sensors, local controllers, independent hardware interlocks,
    fail-safe design, appropriate backflow protection, and applicable
    regulatory review.

## Current project scope

The **About PIPEPURE** screen identifies the following as not yet
implemented:

-   FastAPI backend
-   PostgreSQL database
-   MQTT device communication
-   Login and role-based access
-   Docker setup
-   Reports pages

The current project is therefore a standalone browser prototype, not a
deployed SaaS or production control system. GitHub can host the source
code, but uploading this HTML file alone does not create the missing
backend or connect physical hardware.
